# نسخ جلسات Chromium المشفّرة — مرحلة آمنة منفصلة

جلسات Chromium حساسة جدًا وقد تتضمن **كوكيز تسجيل الدخول**، وبالتالي يجب
التعامل مع أي نسخة باعتبارها وسيلة محتملة للدخول إلى حساباتك. لذلك
فصلناها تمامًا عن أرشيف PostgreSQL، ولا يتضمن جدول النسخ اليومي
ملفات المتصفح.

## شروط الأمان قبل النسخ

- **أوقف عمل Chromium بنفسك أولًا** بعد إنهاء المراجعة وإغلاق المهام.
  السكربت يرفض النسخ إذا كانت حاوية `browser-worker` شغالة أو
  كان Docker Volume مستخدمًا من حاوية أخرى. لا يحاول إيقاف المتصفح
  أو قطع الجلسة تلقائيًا.
- من جذر المشروع على Windows:
  ```powershell
  docker compose -f compose.browser.yml stop browser-worker
  ```
- احتفظ بكلمة مرور قوية لا تقل عن 16 حرفًا، **مختلفة عن كلمات مرور
  حساباتك**. يجب تخزينها في مدير كلمات مرور موثوق خارج الجهاز أيضًا.

## إنشاء نسخة مشفّرة

```powershell
.\scripts\windows\browser-profile.ps1 -Backup
```

أو اختر مسارًا خاصًا بعيدًا عن GitHub:

```powershell
.\scripts\windows\browser-profile.ps1 -Backup -OutputPath "D:\PrivateBackups\chromium-2026.pawprofile"
```

ينشئ الأرشيف ملف `.pawprofile` مستقلًا، مشفّرًا بـAES‑256‑GCM
مع scrypt، وبعلامة تنسيق خاصة تمنع الخلط مع ملفات `.pawbak`.
تُقرأ البيانات من Docker Volume **للقراءة فقط**، وتُشفّر مباشرة دون
حفظ tar غير مشفر على القرص وقت النسخ.

## فحص سلامة الأرشيف دون استخراج

```powershell
.\scripts\windows\browser-profile.ps1 -Verify -InputPath "D:\PrivateBackups\chromium-2026.pawprofile"
```

يتحقق من سلامة الملف وكلمة المرور دون إظهار كوكيز أو بدء Chromium.

## الاستعادة — ممنوع استبدال ملف الجلسة الأصلي

أوقف المتصفح أولًا أيضًا، ثم:

```powershell
.\scripts\windows\browser-profile.ps1 -Restore -InputPath "D:\PrivateBackups\chromium-2026.pawprofile"
```

الاستعادة لا تعدّل Docker Volume الذي يستخدمه المتصفح. تنشئ **Volume جديدًا
غير متصل بأي خدمة** باسم يبدأ بـ`paw_profile_restore_`، وتعرض
اسمه المحلي لمراجعته لاحقًا. لا يوجد أي تبديل تلقائي إلى هذا
الـVolume، ولا تشغيل متصفح عليه أو محاولة تسجيل دخول.

أثناء الاستعادة، وبعد التأكد من كلمة المرور وتوقيع الملف، يُستخرج
أرشيف tar غير مشفر مؤقتًا في مجلد نظام التشغيل ثم يُحذف.
**تشفير القرص الكامل BitLocker مهم جدًا**، لأن حذف الملفات المؤقتة على
SSD لا يضمن محو محتوياتها فورًا.

## القيود الحالية

- ملفات Chromium قد تتضمن بيانات مشفرة بنظام تشغيل الجهاز أو إصدار
  المتصفح؛ لا يمكن ضمان نقل جلسة تسجيل دخول نشطة إلى كمبيوتر آخر
  أو إلى إصدار مختلف من Chromium.
- لا يوجد دمج تلقائي للجلسات، ولا استيراد إلى الملف الشخصي الحالي،
  ولا نسخ تلقائي لبيانات المتصفح وقت جدول PostgreSQL اليومي.
- لا تُرفع أرشيفات `.pawprofile` إلى GitHub أو Lovable. إن نقلتها
  بنفسك إلى تخزين سحابي، حافظ على عبارة المرور بصورة منفصلة.
- الاستعادة في Volume جديد تبقى غير مفعلة عمدًا لحماية جلساتك الحالية.
  الربط بهذا الـVolume يحتاج اختبارًا منفصلًا قبل السماح به.
- اختبارات GitHub تستخدم **كوكي اصطناعية** وليست حسابات شخصية؛
  ويستخدم تشغيل Chromium في CI وضعًا مؤقتًا دون شبكة،
  وليس دليلًا على جاهزية Windows أو ضمان استمرار جلسات مواقع حقيقية.
