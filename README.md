# المتصفح الذكي — Browser + AI Assistant

**الفكرة بسيطة:** تفتح الموقع في Chromium، وتختار التاب، وتكتب
للمساعد أمرًا ينفذه على **نفس التاب**. صفحة المتصفح هي الصفحة
الرئيسية، وبجانبها خانة التعليمات. القائمة المختصرة: المتصفح،
سجل المهام، الإعدادات. لا توجد بيانات تجريبية في المعاينة.

[افتح المشروع في Lovable](https://lovable.dev/projects/d8eb5115-13ea-4fc2-9819-de495b7a7f34) ·
[قائمة ما يعمل وما لم يعمل بعد](docs/CURRENT_STATUS.md)

## حالة الوظائف الفعلية

| القدرة | الوضع |
|---|---|
| تبويبات Chromium وتصفحه يدويًا وعرضه بـnoVNC | موجودة واختُبرت داخل حاويات CI |
| أوامر Ollama لنفس التاب: قراءة، تمرير، فتح رابط آمن، ملء نص دون إرسال | موجودة؛ اختُبرت إجراءات Playwright على صفحة اختبار محلية معزولة |
| تثبيت جلسة Chromium وحفظ المهام في PostgreSQL | موجود؛ اختبارات CI |
| أي ضغط على زر أو إرسال/نشر/شراء/حذف تلقائي | **غير مدعوم حتى الآن** |
| تشغيل المستخدم على Windows مع نموذج Ollama حقيقي | **لم يُختبر بعد** |

**مهم:** Lovable تعرض الشكل وحالة عدم الاتصال الحقيقية؛ لا يمكنها
تشغيل Chromium أو Ollama الموجودين على جهازك من المعاينة المستضافة.

## تحقق تكامل الخدمات (19 أكتوبر 2026)

نجحت **73 من 73** اختبارات الخادم وPostgreSQL في GitHub Actions،
ونجحت **111 من 111** اختبارات الواجهة والبناء. شملت اختبارات الخادم
الجديدة اتصال Fastify بقاعدة PostgreSQL حقيقية وبخوادم HTTP تجريبية
تحاكي Ollama وعامل المتصفح؛ كما جرى التحقق من حفظ المحادثة ورفض
صلاحيات المتصفح غير المصرّح بها.

[تقرير CI الموثق](https://github.com/Ahmedmadni/pixel-perfect-clone/actions/runs/39215358382).

**لم يتم تشغيل نموذج Ollama حقيقي على جهاز المستخدم بعد.** سكربت Windows
`scripts/windows/diagnose.ps1 -TestInference` مخصص لفحص نموذج محلي
فعلي بعد تثبيت البرنامج والنموذج، ولا يطبع محتوى الرد أو الأسرار.

## تشغيل محلي مبسّط

بعد تثبيت Docker Desktop وNode.js وBun وOllama وتثبيت نموذج محلي،
شغّل من جذر المشروع:

```powershell
.\scripts\windows\launch.ps1
```

السكربت يجهز الإعداد أول مرة فقط (ولا يستبدل أسرارًا موجودة)،
ثم يبدأ الخدمات. راجع [دليل Windows](docs/WINDOWS_QUICKSTART.md).
**لا تُدخل رموز الخادم في Lovable المستضاف.**

## تشخيص الاتصال من داخل التطبيق

إذا ظهرت عبارة «المساعد غير جاهز»، افتح **الإعدادات ← فحص جاهزية الخدمات المحلية**.
تعرض الصفحة حالة Fastify وPostgreSQL وChromium وnoVNC وOllama، وتوضح
عندما لا يكون نموذج محلي مثبتًا أو تفويض الخادم غير صحيح. زر «تحديث الفحص»
يعيد قراءة الحالات فقط؛ لا يشغّل أي مهمة ولا يطبع أو يرسل كلمة مرور أو رمزًا.

في حالة تعذر تشغيل Windows، يمكنك استخدام فحص PowerShell الآمن
`./scripts/windows/diagnose.ps1` من جذر المستودع؛
تظل المعاينة المستضافة على Lovable منفصلة تمامًا عن خدمات جهازك.

[نتائج الاختبارات السحابية بعد التحديث (18 أكتوبر 2026)](https://github.com/Ahmedmadni/pixel-perfect-clone/actions/runs/39095164517).

## النسخ الاحتياطي

أُضيف مسار نسخ احتياطي **مشفّر AES-256-GCM** لقاعدة PostgreSQL،
باستخدام كلمة مرور يُدخلها المستخدم محليًا. النسخة لا تُحفظ في
GitHub، والاستعادة تتم في قاعدة جديدة حتى لا تُمس البيانات الأصلية.

- [دليل النسخ المشفر والاستعادة](docs/BACKUP_AND_RESTORE.md)
- [أوامر تشغيل Windows](docs/WINDOWS_QUICKSTART.md)
- [اختبار التشفير ونسخ/استرجاع PostgreSQL الحقيقي على GitHub](https://github.com/Ahmedmadni/pixel-perfect-clone/actions/runs/38883955794)

لا يشمل هذا الأرشيف كوكيز المتصفح أو ملفات `.env` أو نماذج Ollama،
ولا يوجد حتى الآن جدولة تلقائية للنسخ أو واجهة HTTP تستقبل كلمة المرور.

### جدولة نسخ يومية اختيارية

على Windows يمكن تفعيل النسخ المشفّر باستخدام
`scripts/windows/scheduled-backup.ps1 -Enable` بعد الإعداد المحلي؛
لا يُسجّل أي جدول تلقائيًا، وتُحمى عبارة المرور باستخدام DPAPI لحساب
Windows، ولا تُحذف النسخ السابقة تلقائيًا. التفاصيل في
[دليل النسخ والاستعادة](docs/BACKUP_AND_RESTORE.md).

### نسخة مشفّرة لملفات جلسات Chromium (يدوية فقط)

يمكن الاحتفاظ بأرشيف `.pawprofile` منفصل عن نسخ PostgreSQL باستخدام
`scripts/windows/browser-profile.ps1`. يتطلب هذا **إيقاف المتصفح
يدويًا** أولًا، ويرفض النسخ إذا كانت حاوية Chromium قيد التشغيل.
الاستعادة تكون في Docker Volume جديد غير موصل بالتطبيق، ولا تستبدل
كوكيز جلسات العمل الحالية. اقرأ
[الدليل الأمني لجلسات Chromium](docs/CHROMIUM_PROFILE_BACKUPS.md)
قبل استخدامه على حسابات حقيقية.

## الخصوصية والأمان

- لا تُضع رمز `RUNTIME_TOKEN` أو ملفات `.env` أو كوكيز المتصفح على GitHub أو Lovable.
- عرض Lovable السحابي يُستخدم للتطوير/المعاينة، ولا يحصل تلقائيًا على متصفح الجهاز أو رموزه.
- جميع المنافذ المحلية مربوطة بـ`127.0.0.1`.
- لا تُفعّل تجاوز Sandbox المتصفح لتصفح الحسابات الحقيقية.
- وضع التشغيل المعتمد حاليًا: **مراجعة للقراءة فقط**؛ لا يوجد منفّذ لنشر المنشورات أو إرسال الرسائل.
